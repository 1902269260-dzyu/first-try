# 志愿数据处理小工具

一张「姓名、学号、邮箱、志愿1、志愿2、推荐人」的志愿 CSV，三步帮你处理干净：

| 需求 | 命令 | 做什么 |
|------|------|--------|
| 1 读入与概览 | `python main.py overview <文件>` | 多少行、每列几个空值、有没有完全重复的行 |
| 2 校验与清洗 | `python main.py validate <文件>` | 学号/邮箱规则校验、找重复报名，导出「问题清单」（**不改原文件**） |
| 3 统计与导出 | `python main.py stats <文件>` | 按志愿1分组人数、两个志愿填写情况，导出干净数据 CSV |

## 环境要求

- Python 3.8 及以上，**零第三方依赖**（只用标准库），无需 `pip install`。
- Windows 打开命令行：在文件夹地址栏输入 `cmd` 回车即可。

## 快速开始（复制粘贴就能跑）

```bash
git clone https://github.com/1902269260-dzyu/volunteer-tool.git
cd volunteer-tool

# 一条命令跑完三个需求（自带样例数据）
python main.py all data/sample.csv --id-len 10

# 也可以分开跑
python main.py overview data/sample.csv
python main.py validate data/sample.csv --id-len 10
python main.py stats    data/sample.csv --id-len 10
```

处理你自己的文件：把 CSV 路径替换即可，例如 `python main.py all 我的志愿表.csv`。

跑完后输出目录 `out/` 里会生成三个文件：

- `issues.csv` —— 问题清单：每个问题行 + 原文件行号 + 具体原因（需求 2）
- `summary.csv` —— 志愿1分组人数汇总表（需求 3）
- `clean.csv` —— 清洗后的干净数据（需求 3）

## 校验规则

1. **学号**：非空且必须是纯数字；传 `--id-len N` 时额外校验位数必须为 N。
2. **邮箱**：必须严格等于 `学号@smbu.edu.cn`，对不上即判填错。
3. **必填项**：姓名、志愿1 不能为空；志愿2、推荐人允许为空。
4. **完全重复行**：每一列一字不差才算，概览里会列出。
5. **重复报名**：同一学号出现两次及以上，即使其他列不同也全部标记。
6. 原文件永远只读；所有修改只发生在 `out/` 里的新文件。

## 关键假设（拿不准的边界都写在这里）

- **学号位数**：样例数据是 10 位，但学校规则未确认。因此默认**不校验位数、只校验纯数字**，位数通过 `--id-len` 显式约定。如果学校是 8 位，运行加 `--id-len 8` 即可。
- **清洗口径**：只要出现在问题清单里（含重复报名的双方），该行就**不进入** `clean.csv`，交人工核对后再回填。理由：重复报名的两条记录志愿可能不同，程序无权替你选哪条作数。
- **空值定义**：空字符串或只有空格/制表符算空；不处理全角空格。
- **编码**：自动尝试 utf-8-sig / utf-8 / gbk 读取；导出的 CSV 一律 utf-8-sig，Excel 直接双击打开不乱码。
- **多余/缺失列**：表头多出约定之外的列会被忽略并在概览提示；列数与表头不符的行直接进问题清单。
- **大小写**：邮箱按「去首尾空格后严格相等」比较，不做大小写归一。

## 文件结构

```
volunteer-tool/
├── main.py          # 命令行入口
├── overview.py      # 需求 1：读入 + 概览
├── validation.py    # 需求 2：校验 + 问题清单导出
├── stats.py         # 需求 3：统计 + 干净数据导出
└── data/sample.csv  # 故意埋了多种问题的样例数据
```
